Free usage & limits

Roka is free with usage limits. No payment required.

  • Local CLI: 15K tokens lifetime per device.
  • Hosted API: up to 500K tokens/month, depending on your API key.
  • MCP requires a valid API key with the appropriate access.

Check your dashboard for remaining usage. Manage API keys.
