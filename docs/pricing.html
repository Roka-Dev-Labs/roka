Free CLI. Pro MCP.

Local prune is free with a device quota. Connecting an agent is not.

  • Local CLI prune: 15K tokens lifetime per device; works offline; no API key.
  • Hosted API: up to 500K tokens/month on Pro, trial, or Enterprise keys.
  • MCP connect / serve / watch require a Pro API key. Free-tier keys are rejected.

Check your dashboard for remaining usage. Manage API keys.
