# Soup is free

MIT open source. No subscription. No API key. No quota.

- Local CLI prune: unlimited on your machine; works offline.
- MCP `connect` / `serve` / `watch`: free. `npx roka-mcp connect --agent cursor`
- Log text used by MCP tools stays on the machine.

Install: https://trysoup.dev/install.html  
Docs: https://trysoup.dev/docs/
