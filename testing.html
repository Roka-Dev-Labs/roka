LogHub 2k · 10 Nov 2026 rerun

Testing

Ledger for the shipped engine, roka-mcp/lib/prune.js, on 15 public logpai/loghub *_2k.log files. Call: prune_file(path, budget=4000) with no query. 30,003 lines / 4,178,984 characters in. Mean lines removed 98.3%. Character compression 70×. Write-up: research.

1. Ingest

Public 2k samples, untouched. Three files end with a newline, so the engine counts 2,001 lines on those.

2. Collapse

Only adjacent identical lines merge to one line plus (xN repeated). Differing host or id stays distinct.

3. Rank

This run: no query, so crash-regex, then ±2 neighbors, then recency. Query-first packing exists in the engine; it was not used here.

4. Pack

Whole lines into 4,000 characters. Protected lines that do not fit are omitted, not sliced. No file here exceeded the budget.

How to read this

The table is a 10 Nov 2026 rerun of shipped pruneText on the public 2k files. It measures line removal and whether a crash-regex line survived a 4,000-character pack. It does not measure whether a model then solves the incident.

Public files, one call

LogHub 2k samples from logpai. Same function the MCP server ships. No per-file knobs. Zookeeper is a LogHub source and is not in this 15.

Crash-regex, not “the incident”

A hit is a whole-word match on ERROR / FATAL / CRITICAL / Exception / Traceback / panic. Linux’s only hit is “FPU exception support.” Windows “Failed” does not match.

At least one, not every one

11 / 11 = each of the 11 files with a match still had one after packing. Apache kept 50 of 595. BGL kept 26 of 547. The rest were omitted as whole lines.

Thunderbird check: 2,000 lines, 325,192 characters. Bind-to-port-22 is line 1,466 (73%). tail -c 4000 is 28 lines and misses it. prune_file returns 29 lines / 3,965 characters and keeps both crash-regex lines (vesafb error -6 and the sshd bind), plus their ±2 neighbors. gmetad lines did not collapse — the datasource id differs per line.

Older site figures (92.2% mean, BGL 72.7%, 323,193 Thunderbird chars, bind “62% through”) were a previous ranker or a rounded file. This page is the shipped engine on the public 2k files. Token budgets of 8,000 and totals such as 1.7M are not this run.
