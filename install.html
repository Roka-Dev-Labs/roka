Optional — connect to your AI agent (Pro MCP)

                
One command registers Roka as an MCP server in Claude Code, Cursor, Codex, or Copilot. Your agent can then call prune_file and prune_logs directly.

                

                    
                    export ROKA_API_KEY=rk_live_... && npx roka-mcp connect --agent claude-code
                

                
Also: cursor · codex · copilot — restart IDE after connect. Watch: npx roka-mcp watch ./logs/dev.log --on-crash
